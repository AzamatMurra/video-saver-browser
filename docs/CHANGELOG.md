# CHANGELOG

## v1.3 — текущая версия
- **Настройки упрощены:** убраны лимиты названия (символы/предложения/слова).
- **Новая настройка:** галочка «Добавлять тег стрима к имени файла» — при выключении
  в имя файла не вставляется тег стрима (осторожно: одинаковые заголовки перезаписываются).
- **Новое поле «Папка для файлов»:** каталог сохранения выбирается перед постановкой в очередь,
  запоминается, папка создаётся автоматически.

## v1.2
- **Очередь загрузок:** задачи автоматически встают в очередь, если слоты заняты
  (лимит одновременных загрузок настраивается).
- **История загрузок = очередь:** список всех попыток (в очереди / качает / готово / ошибка)
  с прогрессом и готовыми путями; кнопка «Очистить историю».
- **Очередь переживает навигацию:** живёт на сервере, а не во вкладке.
- **Прогресс починен:** удалён `--print` из вызова yt-dlp (он подавлял вывод прогресса),
  имя файла теперь определяется по строкам `[Destination]/[Merger]/already downloaded`.
- **Название файла от заголовка страницы** (поле редактируется).
- Поле ручной ссылки скрыто (расширение само находит потоки).

## v1.1
- Расширение само перехватывает `.m3u8`-потоки страницы (webRequest, per-tab),
  а не шлёт в yt-dlp адресную строку (для таких сайтов, как образовательные платформы,
  yt-dlp «из коробки» не умеет).
- Сервис переведён на `localhost`.
- Выбор потока (master/media_N) и качества (1080p / до 480p).

## v1.0
- Первичная версия: расширение передаёт ссылку локальному Python-сервису,
  который качает через `yt-dlp -f "bv*+ba/b"` — видео и аудио отдельными дорожками
  и склеивает их в MP4 (решение проблемы «видео без звука»).
